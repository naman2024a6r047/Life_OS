# LifeOS — Personal Accountability & Goal Operating System

LifeOS is an all-in-one personal accountability, goal tracking, study management, fitness, and developer productivity web application built with a modern dark-theme user interface.

---

## ✨ Features & Modules

- **📊 Dashboard**: Life Score dial (78/100), active challenge progress, 4 quick-access module cards, activity heatmap, and life score trend graph.
- **🎯 Goals & Challenges**: 90-day structured goal roadmaps with auto-generated 10-day milestone sprints (M1 to M9) and daily task checklists with tag categories.
- **👥 Accountability & Friends**: Accountability partners dashboard with online status, grace tokens, progress bars, activity calendar grid, pending inquiry responses, and penalty history.
- **📝 Peer Review**: Community code & milestone evaluation with 4-dimension star ratings (Quality, Completeness, Consistency, Creativity), feedback forms, evidence galleries, and milestone approvals.
- **🛡️ Exam Mode**: Focus-mode testing environment with problem statements, syntax-highlighted code boxes, question palette grid, countdown timer dial, and anti-cheating secure monitoring.
- **🏋️ Gym & Fitness**: Fitness tracker featuring Push/Pull/Legs workout breakdown, muscle group anatomical graphics, volume history charts, personal records (PRs), nutrition macro donuts, and body stats tracking.
- **💻 Developer Profile**: Developer portfolio with role stats, contribution calendar, top skills progress bars, featured projects showcase, recent commits feed, GitHub activity heatmap, and language distribution.
- **📚 Study Tracker**: Study time overview donut chart, daily study trend bar graphs, study streak tracker, recent study sessions log, focus insights, and subject progress tracking.
- **📈 Analytics**: Deep productivity insights with stacked study overview bars, time distribution donuts, subject performance tables, focus vs break time ratios, and weekly multi-metric summary.
- **⚠️ Penalty System**: Discipline enforcement system with rule definitions, active penalty status ("Goal Set Restart"), strike tracking (2/3 strikes), warning level cards, and penalty history logs.
- **📅 Calendar**: Full monthly calendar scheduler with color-coded event badges (Study, Exam, Health, Tasks, Review), daily summary bars, mini calendar date picker, and upcoming events feed.
- **📚 Resources Hub**: Curated study resource hub with category filters (Study Materials, Practice Papers, Cheat Sheets, Videos, Books), featured roadmaps, resource library table, and contribution uploads.

---

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite, Tailwind CSS, Framer Motion, React Icons, Axios, React Router DOM
- **Backend**: Express.js, Sequelize ORM, SQLite / PostgreSQL
- **Authentication**: Supabase Auth
